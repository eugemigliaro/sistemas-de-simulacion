# Notas de clase

1. Ejecutá `./scripts/nueva_nota.sh "tema"` antes o durante la clase.
2. Escribí libremente en el archivo creado dentro de `bandeja/`.
3. Pedile al agente `procesá mis notas`.

El agente contrasta las notas con fuentes de la cátedra, actualiza la wiki cuando aportan valor, mueve el original intacto a `procesadas/` y registra el resultado en `registro.tsv`. Una opinión o recuerdo personal nunca pasa a presentarse como afirmación oficial sin evidencia.
