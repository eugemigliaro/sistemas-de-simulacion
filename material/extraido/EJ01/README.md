# EJ01 — archivos de ejemplo del CIM

Derivado buscable del contenedor oficial `ArchivosEjemplo.zip`. Se omitieron metadatos de macOS y se preservaron los cuatro archivos de datos:

- `Static100.txt`: encabezados `N` y `L`, seguidos por radio y propiedad de 100 partículas.
- `Dynamic100.txt`: un tiempo y las coordenadas de las 100 partículas.
- `FormatoOutput_CIM.txt`: especificación de la lista de vecinas y definición de distancia borde a borde.
- `AlgunosVecinos_100_rc6.txt`: salida parcial de ejemplo para 100 partículas y radio de interacción 6.

El ZIP catalogado es la autoridad; estos archivos son derivados regenerables.
