# Referencias e influencias

Este proyecto implementa código y documentación propios bajo MIT. No incorpora código copiado de los proyectos siguientes; reconoce sus ideas y experiencia pública.

- [Andrej Karpathy — LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f): patrón de fuentes inmutables, wiki compilada y esquema para agentes.
- [claude-obsidian](https://github.com/AgriciDaniel/claude-obsidian): procedencia explícita, fuentes preservadas, bandeja de entrada y operaciones recuperables.
- [obsidian-wiki](https://github.com/Ar9av/obsidian-wiki): skills portables, compilación incremental y compatibilidad multiagente.
- [llm-wiki-compiler](https://github.com/atomicstrata/llm-wiki-compiler): validación, revisión, frescura y perfiles de dominio.
- [Foam](https://github.com/foambubble/foam): conocimiento Markdown local, enlaces y uso opcional desde VS Code.
- [Material for MkDocs](https://github.com/squidfunk/mkdocs-material) y [Quartz](https://github.com/jackyzha0/quartz): alternativas futuras para publicar la wiki como sitio estático.

## Diferencia educativa

Este template agrega una ontología liviana de materia: cátedra, clases, unidades, notas, guías prácticas, entregables, repaso y laboratorio. También define tutoría adaptativa y prioridad de la fuente oficial.
